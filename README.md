# The Learning Atelier

Professional after-school learning and daycare website built with Next.js, TypeScript and Tailwind CSS.

## Stack
- Next.js App Router
- React 19
- TypeScript
- Tailwind CSS
- Lucide icons

## Local development
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm start
```

## Deployment
Designed for zero-config Vercel deployment from the `main` branch.
